**Student Name:** Obemaro Jahswill Obovie  
  
**Institution:** Miva Open University  

## Project Overview
This repository contains the practical Continuous Assessment portfolio for MIT 8103. The project demonstrates the end-to-end design, optimization, and cloud architecture strategy for the **University of Lagos (UNILAG) – Academic Records and Result Management Portal**. 

## Repository Structure
The project is divided into five progressive modules, covering both relational and non-relational database concepts:

* **[Portfolio 1: Database Design and Modelling](./portfolio-1-database-design)** 
  Contains the 3NF relational schema, SQL mock data generation scripts, and the visual Entity-Relationship (ER) diagram.
* **[Portfolio 2: Query Processing and Optimisation](./portfolio-2-query-optimisation)** 
  Demonstrates transcript generation queries, execution plan analysis (`EXPLAIN`), and performance tuning via B-Tree indexing.
* **[Portfolio 3: Transactions and Concurrency](./portfolio-3-transactions-concurrency)** 
  Implements row-level locking (`SELECT ... FOR UPDATE`) to prevent lost update anomalies during simultaneous grade entries.
* **[Portfolio 4: NoSQL Implementation](./portfolio-4-nosql)** 
  Outlines a Document-based NoSQL architecture (JSON/MongoDB) for handling high-velocity, unstructured LMS Activity Logs.
* **[Portfolio 5: Distributed Cloud Architecture](./portfolio-5-distributed-cloud)** 
  Details a cloud deployment strategy using Master-Slave replication and horizontal sharding, including infrastructure-as-code deployment evidence.
